# Floating Contact

SnapCart includes floating contact buttons that allow customers to quickly reach you via popular messaging channels.
The buttons appear as a fixed overlay on all pages.

## Supported Channels

- **Phone**: Initiates a phone call
- **Zalo**: Opens Zalo chat with your store
- **WhatsApp**: Opens a WhatsApp chat
- **Messenger**: Opens Facebook Messenger chat
- **Telegram**: Opens a Telegram chat
- **Custom URL**: Opens any link you provide

## Configuration

To configure floating contact buttons, go to `Appearance` -> `Theme Options` -> `Contact` in the admin panel.

Up to 3 buttons can be configured. For each button, fill in the following fields:

- **Button type**: Phone, Zalo, WhatsApp, Messenger, Telegram or Custom URL (select `-- Disabled --` to hide the button)
- **Button value**: Phone number, username, or URL
- **Button label (optional)**: Leave empty to use the default label

## Enable/Disable

You can toggle the floating contact feature on/off in `Appearance` -> `Theme Options` -> `Features` -> **Enable floating contact buttons**.

::: tip
Floating contact buttons are especially effective on mobile where customers prefer messaging over email. Keep your
response times fast to maximize conversions.
:::
