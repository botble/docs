# Release Notes

## 1.0.0 (2026-10)

- Initial release
- 3 homepage presets: Creative Studio, Modern Agency, Digital Startup
- 25 UI blocks (shortcodes) with 85 style variants
- 9 project layouts, including WebGL showcase layouts
- 5 header styles and 3 footer styles, with a per-page override
- Overlay menu with a preview image per link
- Dark mode / light mode (system, light or dark default) with optional visitor switcher
- Portfolio projects and services with tags, year, showcase tone, spec rows, client quotes and outcome metrics
- Team members and careers with an apply form
- Contact form, FAQ, testimonials, pricing plans, process steps and blog
- Newsletter sign-up section and optional newsletter popup (shown on the demo homepage)
- Logo, favicon and dark mode logo settings, with logo size controls
- Preloader and 404 page settings
- Smooth scrolling, custom cursor and mouse-follow effects, each with an on/off option
- Multi-language support through the Language plugin, with a language switcher in the overlay menu
- RTL support (Arabic demo content included)
- Google Analytics through the Analytics plugin
