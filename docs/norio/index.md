# Norio - Digital Agency & Portfolio

## Introduction

**Norio** is a Digital Agency & Portfolio theme built on Botble CMS. It suits design studios, digital agencies, startups and freelancers who want a portfolio-first website with projects, services, team, careers and a blog. Norio is a content theme: it has no shop, cart or checkout.

![Norio overview](./images/overview.webp)

Norio is built on Botble CMS, a Laravel-based CMS. Every section of the homepage and inner pages is an editable UI block, so you can rebuild a page without touching code.

## Features Overview

* **3 Homepage Presets** - Creative Studio, Modern Agency and Digital Startup, selected during installation
* **25 UI Blocks (Shortcodes) with 85 Style Variants** - page heroes, about, features, portfolio projects, services, team, testimonials, FAQs, pricing, process steps, calls to action, blog, careers and contact
* **9 Project Layouts** - including a full-screen showcase, three WebGL layouts and a filterable grid
* **5 Header Styles + 3 Footer Styles** - set site-wide in Theme Options and overridden per page
* **Overlay Menu** - full-screen navigation with a preview image per link
* **Dark Mode / Light Mode** - default mode set in Theme Options, optional visitor switcher
* **Portfolio Details** - tags, year, showcase tone, spec rows, client quotes, gallery lightbox and outcome metrics
* **Team and Careers** - member profiles and job listings with an apply form
* **Motion Options** - smooth scrolling, custom cursor and mouse-follow effects, each can be switched off in Theme Options
* **Preloader** - optional loading screen with a configurable image
* **Contact Form and Newsletter** - built on the Contact and Newsletter plugins, with an optional newsletter popup
* **Multi-Language and RTL** - Language plugin support with a language switcher in the overlay menu, right-to-left layout for Arabic and other RTL languages, and theme strings translated into 24 languages
* **Google Analytics** - through the Analytics plugin
* **Based on Botble CMS** - Laravel framework with the admin panel, SEO helper and sitemap
* **Fully Customizable** - all text, images and settings editable from the admin panel
