# Menus

Menus are the navigation links of your site. Create them in the admin panel, then assign each one to a **display location**. The theme shows the menu of each location in its place in the header.

## Create a Menu

1. Go to `Appearance` -> `Menus` and create a menu.
2. Add links and arrange them.
3. Open **Display location**, choose a location from the table below and save.

## Menu Locations

| Location | Admin name | Shown in |
|----------|------------|----------|
| `main-menu` | **Main Navigation** | Navigation bar of the header styles that show the main menu, for example Default, Organic and Furniture |
| `header-category-menu` | **Header category navigation** | Category navigation of the Marketplace 2, Technology, Electronic and Auto parts headers. While empty, these headers show the **Main Navigation** menu |

The footer link columns do not use a menu location. Build them with **Custom Menu** widgets in the footer sidebar. See [Widgets](./usage-widgets.md).
