## Features

- **12 homepage demos**: Multipurpose, Marketplace 1 to 4, Technology, Electronic, Furniture, Organic, Auto parts, Kids and Medical. Pick one in the installer, see [Homepage demos](./usage-homepage.md).
- **12 header styles and 4 footer styles**, set in [Theme options](./usage-theme-options.md).
- **UI blocks** with style options, plus 8 `ecommerce-*` blocks, see [UI Blocks](./usage-ui-block.md).
- Multi-vendor marketplace, with [vendor subscriptions](./usage-marketplace-subscriptions.md).
- Color, label and image swatches, AJAX filters, live search, wishlist and compare.
- Multi-language with RTL support and multi-currency.
