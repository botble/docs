# Widgets

Widgets are small blocks you place in widget areas, such as the footer or the blog sidebar. Martfury uses widgets for the footer link columns and the blog sidebar.

## Manage Widgets

Go to `Appearance` -> `Widgets` in the admin panel. Drag a widget from the list into a widget area. To remove it, drag it back or delete it from the area.

## Widget Areas

| Widget area | Where it shows | Notes |
|-------------|----------------|-------|
| **Primary sidebar** | Blog Sidebar page template | Widgets beside the blog posts |
| **Footer sidebar** | Link columns of the Default, Link columns + newsletter, Site features + link columns and Contact + link columns + newsletter footers | Each column is a **Custom Menu** widget |
| **Bottom Footer sidebar** | Row of links below the footer columns | Default and Site features + link columns footers. The Site features footer hides it with the Kids homepage style |

The demos fill the footer sidebar with three **Custom Menu** widgets (Quick links, Company and Business). Create the menus in `Appearance` -> `Menus` first, then pick them in each widget.

## Widgets

| Widget | Shows |
|--------|-------|
| **Blog Categories** | List of blog categories |
| **Blog Search** | Search box for blog posts |
| **Custom Menu** | A menu you choose from `Appearance` -> `Menus` |
| **Product Categories** | List of product categories |
| **Recent posts** | Latest blog posts |
| **Tags** | Popular tags |

::: tip
Use **Custom Menu** to build footer link columns. Each widget shows one menu, so create one menu per column.
:::
